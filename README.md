<hr/>

<h2>📌 Project Overview</h2>

<p>
QuickSuite is a modern web application built to provide essential digital tools directly in the browser — without requiring server uploads or database storage.
</p>

<p>
The core philosophy behind QuickSuite:
</p>

<ul>
  <li>Process everything locally in the browser</li>
  <li>Ensure user privacy (no file storage)</li>
  <li>Deliver fast performance even on low-end devices</li>
  <li>Provide clean, distraction-free UI</li>
</ul>

<hr/>

<h2>🚀 Tech Stack</h2>

<ul>
  <li><strong>Framework:</strong> Next.js (App Router)</li>
  <li><strong>Language:</strong> TypeScript</li>
  <li><strong>Styling:</strong> Tailwind CSS</li>
  <li><strong>State Management:</strong> React Hooks</li>
  <li><strong>File Processing:</strong> pdf-lib, pdf.js</li>
  <li><strong>Image Tools:</strong> Browser-based processing APIs</li>
</ul>

<hr/>

<h2>⚡ Architecture Strategy</h2>

<ul>
  <li>Client-side file handling (no backend dependency)</li>
  <li>Dynamic imports for heavy libraries</li>
  <li>Code splitting for optimized bundle size</li>
  <li>Lazy loading components where required</li>
  <li>Mobile-first responsive layout</li>
</ul>

<hr/>

<h2>🛠 Core Features</h2>

<ul>
  <li>PDF Merge & Compression</li>
  <li>Image Compression & Conversion</li>
  <li>EMI Calculator</li>
  <li>Salary & Loan Calculators</li>
  <li>Browser-based utility tools</li>
</ul>

<hr/>

<h2>🔒 Privacy & Performance</h2>

<ul>
  <li>No file uploads to server</li>
  <li>No database storage</li>
  <li>All processing happens locally in browser memory</li>
  <li>Optimized for fast interaction</li>
</ul>
